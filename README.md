# My Journey of Learning English — 高中英语学习经验分享

主题：回母校给高中学弟学妹讲英语学习——从应试提分到英语素养。
形式：仿 PPT 网页展示 + 无后端互动页 + 演讲稿，离线可用；除一张本地海报外零依赖。

> ⚠️ 需求或内容发生变更时，必须同步更新本文件（README.md，给人看）和 AGENTS.md（给 AI 看）。

## 文件说明

| 文件 | 用途 | 给谁看 |
|---|---|---|
| `presentation.html` | 展示用幻灯片，16 页，键盘/点击/滑动翻页，内嵌备注、计时器、二维码生成器 | 课堂投屏 |

## 互动设计

> 互动页所有正文均为中英双语（英文在前、中文在后）；展示页第 3、13、14 页的互动内容同样双语。

1. **单人问卷（`?activity=survey`）**
   8 题自查，写死在前端，本地计算三条分维度：
   - 考试痛点 3 题，3–15 分，分档 3–6 低 / 7–11 中 / 12–15 高；
   - 学习习惯 3 题，3–15 分，分越高习惯越好；
   - 态度与课外输入 2 题，2–10 分，分越高越好。
   结果页含痛点总分、三条柱、最高痛点与最薄弱习惯对应的两条建议，以及"举手提示"；
   数据不上传，只留在学生手机上。
2. **抢答（`?activity=race&q=<题号>&start=<开始时间戳>&sign=<签名>`）**
   提前扫码进入倒计时等待页，到 `start` 时刻题目解锁；作答后显示对错与从官方开始时间算起的耗时，
   供台上人工排名。题号 1–3 可切换。测试用 `&preview=1` 可立即解锁。
   作答页的题干与选项只显示英文，结果页与提示仍是中英双语。
   等待页会自动校准手机时钟（并发 HEAD 取服务器 `Date` 头，开赛前持续补采样），
   徽标显示 `Clock synced · 时钟已同步 · ±X.X s` 的不确定度；校不准或离线时显示
   `Using device clock · 使用设备时钟`。受 HTTP 头只有整秒精度所限，耗时按 0.1 秒
   显示，别把它当成毫秒级计时器。
   **每题只能答一次**：点选后答案字母写入链接的 `answer` 参数、实际用时（毫秒）写入 `t` 参数
   （`history.replaceState`，不新增历史记录），刷新页面直接回到已答结果页且显示同一用时，
   不会再次出题；`answer` / `t` 非法时不生效（`t` 缺失时才按当前时间回算）。
   只有 `preview=1` 的"再测一次"会清空这两个参数。
   **只能从二维码进入**：直接打开互动页（不带任何参数）只显示自查问卷入口与"请扫码参与"提示，
   不提供抢答入口；`?activity=race` 若缺少合法 `start` 且没有 `preview=1`，
   也只显示扫码提示，不出题。
   **链接带签名、缺失即拦截**：第 14 页生成的二维码与复制链接都带 `sign`
   （由题号、开始时间、预览开关、作答后的答案与用时共同决定）。手改地址栏里的任何一项
   （提前 `start`、给普通链接加 `preview=1`、改 `t` 骗用时），或直接丢掉 `sign`，
   互动页都会只显示一句中英冷幽默 + "请重新扫描二维码"，不出题、也不给结果。
   说明：项目无后端，盐只能写在网页源码里，所以这是防手改网址的威慑与彩蛋，
   不是真正的防作弊机制。
3. 全程无后端：无服务器、无存储、无第三方接口，二维码在页面内本地生成。

## 上场前准备

1. 把 `presentation.html`、`interaction.html` 和 `spider-man-poster.avif` 三个文件
   放到同一个静态目录（GitHub Pages、Netlify Drop、校内服务器皆可），三者必须同级。
2. 打开 `presentation.html`，按 <kbd>S</kbd> 打开设置面板，填写 interaction.html
   的完整网址（可选勾选 Preview 预览模式），二维码会实时生成并保存在本浏览器。
3. 翻到第 14 页（抢答环节），在抢答二维码下方：
   - 秒数框填 N，点 "Apply · 应用"，开始时间即设为"当前时间 + N 秒"
     （课前 3 分钟开赛就填 180）
   - 题号下拉框选 1–3，选完二维码实时更新
4. 手机扫码自测两个链接都能打开；确认第 12 页海报正常显示。
5. 按 `speech.txt` 末尾的"课前 10 分钟检查清单"过一遍。

## 时间结构（约 14 分钟）

正文英文约 1050 词，含两次互动各约 2–3 分钟。压缩至 10 分钟的砍法见 speech.txt 应急预案第 5 条。

## 兼容性

两个页面的兼容要求不同，按页面分级：

- **互动页**（学生手机扫码，设备不可控）要求最高：按 2021 年后的手机浏览器保底，
  不用 `color-mix()`，视口单位用 `dvh` 时必须同时写 `vh` 回退。
- **展示页**（投屏设备可控）可用全部 Baseline 特性，不必再写回退。
- 海报是 AVIF；投屏电脑建议用近几年的 Chrome / Edge / Firefox，或提前确认能显示。

两页都支持系统的"减少动态效果"设置。

## 修改内容

- 改幻灯片文字：直接编辑 `presentation.html` 中对应 `<section class="slide">` 的文字。
- 改名单：第 2 页与第 16 页的 `.role` 同步改，讲稿第 2 段同步改。
- 改问卷题目 / 抢答题目：编辑 `interaction.html` 顶部 `SURVEY`、`FOCUS` 与 `RACE` 数据。
- 改讲稿：编辑 `speech.txt`（保持页码与幻灯片一致，页码/角色一致性见 AGENTS.md）。
- 变更完成后按 AGENTS.md 的要求同步更新 README 与 AGENTS 两个文件。
