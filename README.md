# Why We Freeze — 大学英语课小组展示

主题：二语习得 / 外语焦虑（The Psychology of Speaking a Second Language）
形式：仿 PPT 网页展示 + 无后端互动页 + 演讲稿，全部为单文件、零依赖、可离线使用。

> ⚠️ 需求或内容发生变更时，必须同步更新本文件（README.md，给人看）和 AGENTS.md（给 AI 看）。

## 文件说明

| 文件 | 用途 | 给谁看 |
|---|---|---|
| `presentation.html` | 展示用幻灯片，15 页，键盘/点击/滑动翻页，内嵌备注、计时器、二维码生成器 | 课堂投屏 |
| `interaction.html` | 互动页，全部互动合并于此，靠 `?activity=` 区分 | 学生手机扫码 |
| `speech.txt` | 演讲稿（纯文本非 Markdown），逐页对应幻灯片，6 人分角色 | 演讲者背稿 |
| `README.md` | 人看的使用说明 | 人 |
| `AGENTS.md` | AI 看的项目约定与变更规则 | AI |

## 互动设计

> 互动页所有正文均为中英双语（英文在前、中文在后）；展示页第 9、10、13 页的互动内容同样双语。

1. **单人问卷（`?activity=survey`）**
   心理课式自查，12 题写死在前端，本地计算三维得分（交流恐惧 / 负面评价恐惧 / 测评压力），
   结果页含总分、分维度条形图、建议与"举手提示"，学生举手分享，不上传任何数据。
2. **抢答（`?activity=race&q=<题号>&start=<开始时间戳>`）**
   提前扫码进入倒计时等待页，到 `start` 时刻题目解锁；作答后显示对错与从官方开始时间算起的耗时，
   供台上人工排名。题号 1–3 可切换。测试用 `&preview=1` 可立即解锁。
   **每题只能答一次**：点选后答案字母写入链接的 `answer` 参数、实际用时（毫秒）写入 `t` 参数
   （`history.replaceState`，不新增历史记录），刷新页面直接回到已答结果页且显示同一用时，
   不会再次出题；`answer` / `t` 非法时不生效（`t` 缺失时才按当前时间回算）。
   只有 `preview=1` 的"再测一次"会清空这两个参数。
   **只能从二维码进入**：直接打开互动页（不带任何参数）只显示自查问卷入口与"请扫码参与"提示，
   不提供抢答入口；`?activity=race` 若缺少合法 `start` 且没有 `preview=1`，
   也只显示扫码提示，不出题。
3. 全程无后端：无服务器、无存储、无第三方接口，二维码在页面内本地生成。

## 上场前准备

1. 把 `presentation.html` 和 `interaction.html` 两个文件放到任意静态托管
   （GitHub Pages、Netlify Drop、校内服务器皆可），手机能打开即可。
2. 打开 `presentation.html`，按 <kbd>S</kbd> 打开设置面板，填写：
   - interaction.html 的完整网址
   - 抢答开始时间（HH:MM:SS，如 14:35:00）
   - 抢答题号（1–3）
   二维码会实时生成并保存在本浏览器。
3. 手机扫码自测两个链接都能打开。
4. 按 `speech.txt` 末尾的"课前 10 分钟检查清单"过一遍。

## 展示页快捷键

| 按键 | 功能 |
|---|---|
| ← → / 空格 / 点击 / 滑动 | 翻页（点左侧边缘可回退） |
| Home / End / 数字键 | 跳转首页 / 末页 / 指定页 |
| N | 演讲者备注（每页含主讲人与用时提示） |
| T | 计时器开关（双击计时数字归零） |
| S | 设置面板（网址 / 开始时间 / 题号） |
| F | 全屏 · H 或 ? 帮助 · Esc 关闭面板 |

## 时间结构（约 13–15 分钟）

正文英文约 1550 词 ≈ 12 分钟，含两次互动各约 2 分钟。压缩至 10 分钟的砍法见 speech.txt 应急预案第 5 条。

## 兼容性

两个页面的兼容要求不同，按页面分级：

- **互动页**（学生手机扫码，设备不可控）要求最高：按 2021 年后的手机浏览器保底，
  不用 `color-mix()`，视口单位用 `dvh` 时必须同时写 `vh` 回退。
- **展示页**（投屏设备可控）可用全部 Baseline 特性，不必再写回退。

两页都支持系统的"减少动态效果"设置。

## 修改内容

- 改幻灯片文字：直接编辑 `presentation.html` 中对应 `<section class="slide">` 的文字。
- 改问卷题目 / 抢答题目：编辑 `interaction.html` 顶部 `SURVEY` 与 `RACE` 数据。
- 改讲稿：编辑 `speech.txt`（保持页码与幻灯片一致，页码/主讲人一致性见 AGENTS.md）。
- 变更完成后按 AGENTS.md 的要求同步更新 README 与 AGENTS 两个文件。
